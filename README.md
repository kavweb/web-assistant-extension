# دستیار وب‌گردی (نسخه‌ی ۰٫۱)

## نصب
1. در Chrome برو به `chrome://extensions` و «Developer mode» را روشن کن.
2. «Load unpacked» را بزن و همین پوشه را انتخاب کن.
3. روی آیکون افزونه ← تنظیمات (یا ⚙️ در پنل) کلید رایگان Gemini/OpenRouter بگذار و «تست اتصال» بزن.
4. هر صفحه‌ای را باز کن؛ دکمه‌ی «کمک» پایین‌چپ است (کشیدنی). میان‌بر: Alt+K

## Ollama (محلی)
باید با `OLLAMA_ORIGINS=chrome-extension://*` اجرا شود، وگرنه مرورگر اجازه نمی‌دهد.

## ساختار
- `background.js`: تنها جایی که کلید را می‌بیند؛ سقف روزانه، کش ۷ روزه، سه ارائه‌دهنده
- `content.js`: رابط (Shadow DOM)، هایلایت، خلاصه، ساده‌سازی، رصد رفتار محلی
- `options.*`: تنظیمات و پاک‌کردن اطلاعات

## قواعد ایمنی در کد
- صفحه‌های حساس و دارای رمز عبور: پیش‌فرض خاموش
- مقدار فیلدها هرگز ارسال نمی‌شود
- کلیک خودکار فقط با تأیید، و هرگز روی ثبت فرم، پرداخت، حذف و تأیید
- متن صفحه برای مدل «داده» است نه دستور (دفاع اولیه در برابر Prompt Injection)

## محدودیت‌های شناخته‌شده
iframeها، Shadow DOMهای باز سایت‌ها و برخی SPAها هنوز پوشش داده نمی‌شوند؛ تست روی سایت‌های واقعی لازم است.
